Kebijakan Privasi Penny

Berlaku sejak 17 November 2026 · English version below

Ringkasnya: semua data keuangan kamu disimpan di perangkat kamu sendiri. Penny tidak punya server untuk menyimpan data kamu, tidak menjual data, dan tidak memakai data kamu untuk iklan.

Data yang disimpan

Transaksi, akun, kategori, anggaran, portofolio, dan pengaturan disimpan di browser perangkat kamu (IndexedDB). Data ini tidak dikirim ke server Penny, karena Penny memang tidak punya server penyimpanan. Menghapus data situs di browser akan menghapus data ini, kecuali kamu sudah membuat backup.

Backup Google Drive (opsional)

  • Kalau kamu menyambungkan Google Drive, Penny meminta satu izin saja: drive.appdata. Izin ini hanya membuka folder tersembunyi khusus Penny di Drive kamu.
  • Penny tidak bisa melihat, membaca, atau mengubah file lain di Drive kamu.
  • Isi backup berupa satu file berisi data Penny kamu. File itu dikirim langsung dari browser ke Drive kamu, tanpa lewat server lain.
  • Kamu bisa memutus sambungan kapan saja dari Pengaturan, dan menghapus datanya lewat Google Drive → Setelan → Kelola aplikasi → Penny.

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh Penny mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk ketentuan Limited Use.

Fitur AI (opsional)

Fitur "Tanya AI" memakai API key milik kamu sendiri dari penyedia yang kamu pilih: Google (Gemini), Groq, atau Anthropic (Claude). Saat kamu bertanya, ringkasan keuangan dari periode yang dipilih dan pertanyaan kamu dikirim langsung dari browser ke penyedia tersebut. Data itu tunduk pada kebijakan privasi penyedia masing-masing. API key hanya disimpan di perangkat kamu dan tidak pernah ikut backup atau export.

Harga saham (opsional)

Untuk memperbarui harga saham di portofolio, Penny mengirim kode saham (misalnya BBCA), bukan jumlah atau nilai kepemilikan kamu. Kode saham IDX dan beberapa bursa lain dikirim ke Yahoo Finance lewat proxy Penny. Kode lainnya dikirim ke Twelve Data memakai API key kamu sendiri. Pencarian saham juga lewat Twelve Data.

Scan struk

Fitur scan struk di Patungan membaca foto struk langsung di perangkat kamu. Fotonya tidak diunggah. Yang diunduh hanya file pengenal teks yang dibutuhkan.

Statistik kunjungan

Penny memakai Vercel Analytics untuk menghitung kunjungan halaman secara anonim, tanpa cookie dan tanpa data keuangan. Font dan ikon dimuat dari Google Fonts.

Yang tidak dilakukan Penny

  • Tidak menjual atau menyewakan data kamu.
  • Tidak memakai data kamu untuk iklan.
  • Tidak memakai data dari Google API untuk melatih model AI.

Perubahan dan kontak

Kalau kebijakan ini berubah, tanggal di atas akan diperbarui. Pertanyaan bisa disampaikan lewat github.com/ryanderon.

Penny Privacy Policy

Effective 17 November 2026

In short: all your financial data stays on your own device. Penny has no server that stores your data, does not sell data, and does not use your data for advertising.

Data stored

Transactions, accounts, categories, budgets, portfolio and settings are stored in your browser on your device (IndexedDB). They are not sent to any Penny server; Penny has no storage server. Clearing the site's data in your browser deletes them unless you have a backup.

Google Drive backup (optional)

  • If you connect Google Drive, Penny requests a single scope: drive.appdata. It only grants access to a hidden folder in your Drive that belongs to Penny.
  • Penny cannot see, read or change any other file in your Drive.
  • The backup is one file containing your Penny data, sent directly from your browser to your Drive with no server in between.
  • You can disconnect at any time in Settings, and delete the data in Google Drive → Settings → Manage apps → Penny.

Penny's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

AI features (optional)

"Ask AI" uses your own API key from the provider you choose: Google (Gemini), Groq or Anthropic (Claude). When you ask a question, a summary of your finances for the selected period and your question are sent directly from your browser to that provider, under that provider's privacy policy. API keys are stored only on your device and are never included in backups or exports.

Stock prices (optional)

To update portfolio prices, Penny sends ticker symbols (for example BBCA), never your holdings or their value. IDX and several other exchanges are looked up on Yahoo Finance through Penny's proxy. Other tickers go to Twelve Data with your own API key. Symbol search also uses Twelve Data.

Receipt scanning

Receipt scanning in Split Bill reads the photo on your device. The photo is not uploaded; only the text-recognition data files are downloaded.

Usage statistics

Penny uses Vercel Analytics to count page views anonymously, without cookies and without any financial data. Fonts and icons load from Google Fonts.

What Penny does not do

  • Sell or rent your data.
  • Use your data for advertising.
  • Use data obtained from Google APIs to train AI models.

Changes and contact
